# v5 도움말·국소 손상 구현 결과

2026-09-12. 사용자의 추가 구현 요청에 따라 기존 Pre-QA 후보를 보존하고 별도 v5 작업 사본에서 구현했다. 기존 후보에 대한 PRE-QA GO 판정을 의미하지 않는다.

## 사용 흐름

초보 모드는 자동으로 긴 실습을 띄우지 않고 오른쪽에 작은 도움 버튼만 제공한다. 일반 모드는 도움 버튼과 자동 안내를 숨긴다. F1은 두 모드에서 같은 도움말을 열며 주행을 일시정지한다. 기존 속도계·미니맵·상태 계기는 유지한다.

도움말은 여섯 분류, 24개 목적별 항목으로 구성했다. P/R/N/D와 전진 1~6단을 각각 다룬다. 변속기 설명은 실제 정차·브레이크·클러치·오버레브 검사에 맞추었고, 현재 바인딩을 사용한다. 각 단의 회전 제한 속도도 현재 차량 설정에서 계산한다. 튜닝·성능·카메라 화면과 수리 버튼으로 연결한다.

홈·일시정지·도움말·성능 화면은 선택 언어에 맞춰 표시하고, 그래픽·카메라 메뉴의 주요 영어 문구를 한국어로 정리했다. 기존 일부 계측·진단·차고 문구의 전체 현지화까지 완료한 것은 아니다.

## 손상 처리

- 기존 `DamageFront/Rear/Left/Right` 부위 전체 블렌드셰이프 적용을 제거했다.
- 충돌점과 방향을 차량 로컬 좌표로 저장한다. 긁힘은 접선 방향·속도, 칠 까짐·찌그러짐·범퍼 크랙은 충격 에너지에 따라 분리한다. 미세 잔기스는 생성하지 않는다.
- 원본 메시를 수정하지 않고 외장 메시 사본의 정점만 변형한다. 반경 최대 0.55m, 단일 충격 깊이 최대 0.16m, 중첩 변위 최대 0.24m다. 반대편 표면에는 적용하지 않는다. 도장 아래 재질과 거친 긁힘·크랙은 표면 셰이더로 표현한다.
- 수리는 원본 메시와 기존 재질 덮개를 정확히 복원하고 표면 자국·부위 손상·손상에 따른 출력/조향 저하를 초기화한다. 표시했던 LOD도 함께 복원한다.
- 첫 접촉 틱에서 엔진 충격량이 0인 경우 접근 상대속도와 유효 질량으로 손상 에너지를 추정한다. 텔레메트리에 `incoming_speed_estimate`와 `solver_impulse`를 구분한다. 물리 반응 충격을 추가로 가하지 않는다. 기존 COM 좌표 수정은 유지했다.

게임용 근사 모델이다. 차량당 독립적인 손상 지점은 최대 16개이며 같은 지점의 더 강한 충격은 갱신한다. 원본 충돌 프록시는 변형하지 않는다. 크랙은 플라스틱/복합재 범퍼 표면 표현이며 부품 분리·파편 시뮬레이션은 포함하지 않는다. 마찰력·재료 파괴를 해석하는 공학적 구조 시뮬레이터는 아니다.

충돌 속도는 초기 설정값이며 실제 충돌 순간 속도와 같다고 간주하지 않는다. 넓은 평탄한 노면에서 실제 차량 클래스를 해제한 물리 검사이며, 주행 중 외부에서 추가 충격이나 손상을 직접 주입하지 않았다. 손상 전후 스크린샷과 메시 국소성 검사는 별도의 통제된 렌더/기하 검사다.
