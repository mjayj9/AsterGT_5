# ASTER GT3 v5

이 폴더의 **AsterGT-v5.exe**를 실행하세요.

- 홈 화면의 **도움 표시 → 초보 모드**: 주행 화면 오른쪽에 작은 **? 도움** 버튼이 나타납니다.
- **일반 모드**: 자동 실습·주행 팁·도움 버튼을 숨깁니다. **F1**로 도움말을 엽니다. 속도계·미니맵 등 주행 계기는 유지합니다.
- 도움말에서 하고 싶은 일을 고르세요. P/R/N/D, 전진 1~6단 각각, 클러치, ABS/TCS/ESC, 튜닝, 성능, 카메라와 수리를 다룹니다. 설명은 현재 키 설정에 맞춰 표시됩니다.
- 도움말을 읽는 동안 주행이 멈춥니다. **닫고 주행 계속**으로 돌아갑니다.
- 충돌 손상은 **긁힘 / 칠 까짐 / 찌그러짐 / 범퍼 크랙**으로 나눴습니다. 잔기스는 제외했습니다.
- **Esc → 차량 손상 복구**, 도움말의 손상 항목, 차량 설정의 **차체 수리**에서 원형으로 복구할 수 있습니다. 도로 위치 복구(Backspace)와 수리는 별개입니다.

한국어/English는 홈 화면 또는 키 설정에서 선택합니다. 초보·일반 모드 선택은 저장됩니다. 기본 키를 바꾸면 F1 등 위의 키도 달라질 수 있습니다.

v5 설정은 `%APPDATA%\AsterGT-v5`에 저장됩니다. 기존 v4 Pre-QA 후보와 설정을 보존한 별도 개발 빌드입니다.
