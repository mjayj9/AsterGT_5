# 차량 물리·변속기·튜닝

## 한 상태에서 계산되는 차량

`GTCar`는 RigidBody3D이며 GodotPhysics3D가 선속도, 각속도, 중력, 충돌을 적분합니다. 120Hz 고정 물리 tick에서 네 바퀴의 RayCast 접지, 스프링·댐퍼, 타이어, 엔진·변속기 순으로 계산하고 접점에 힘을 가합니다. 렌더 프레임에서 좌표를 직접 전진시키지 않습니다. 차체의 피치·롤과 앞뒤·좌우 접지 하중 차이가 가속·제동·코너링의 하중 이동을 만듭니다.

바퀴별로 지면 법선, 서스펜션 압축량, 종·횡 속도, 각속도, 접지 하중, 슬립 비율·슬립 앵글을 보관합니다. 종방향 슬립은 접선 속도와 휠 둘레 속도의 차이를 저속 특이점을 피한 분모로 나누어 계산합니다. 횡방향 힘과 종방향 힘의 합은 마찰 원으로 제한합니다. 마찰 한계를 넘으면 힘이 포화되고 잠김 상태에서는 유효 마찰이 줄어듭니다. 각 바퀴의 회전 방정식은 tick 안에서 8번 세분하여 토크·브레이크·노면 반력을 계산합니다. 완전한 Pacejka 타이어 모델이나 유연체 서스펜션 모델은 아닙니다.

ABS는 잠김 방향의 슬립이 커지면 바퀴 제동 토크를 줄이고, TCS는 구동륜 슬립에 따라 엔진 토크를 줄입니다. ESC는 조향·속도로 계산한 목표 요 레이트와 실제 요 레이트 차이에 안정화 토크를 가합니다. 목표 회전율은 μg/v 한계로 제한합니다. 이는 생산차의 개별 브레이크 기반 ESC를 간소화한 것입니다. 핸드브레이크는 후륜을 잠그며, 주차 상태는 경사에서도 접지 정지 마찰을 사용합니다.

공기저항은 속도 제곱과 항력 면적에, 구름저항은 접지 하중에, 다운포스는 속도 제곱에 비례합니다. 앞뒤 제동 배분과 FWD/RWD/AWD 구동 배분을 지원하고, 간단한 차동 제한 토크로 좌우 회전 차이를 제어합니다. 차체 충돌은 낮은 본체 상자와 실내 상자를 사용하며 연속 충돌 감지(CCD)를 켰습니다. 바퀴는 광선 접지이므로 작은 수직 연석·극단적인 모서리 충돌의 재현에는 한계가 있습니다.

## 엔진과 변속기

토크 커브를 RPM에 따라 선형 보간하고 스로틀·보조 개입·변속 토크 컷을 곱합니다. 엔진 브레이크도 구동계에 전달합니다. 구동계가 연결되었을 때 목표 RPM은 다음 관계를 사용합니다.

`평균 구동륜 각속도 × 60/(2π) × 현재 기어비 × 최종 감속비`

RPM 자체는 클러치 연결량, 자유 회전 엔진 상태, 회전 관성을 근사한 보간에 따라 반응합니다. 타코미터와 사운드는 이 실제 엔진 RPM을 사용합니다. 속도계는 강체 선속도 크기를 km/h로 환산합니다. 휠 슬립·기어 변경·클러치 분리 중에는 차량 속도만으로 역산한 RPM과 일치할 필요가 없습니다.

자동 모드에는 P/R/N/D, 스로틀별 변속 기준, 업·다운시프트 히스테리시스, 킥다운, 정지 전 다운시프트, 약한 크리프가 있습니다. 수동 모드에서는 Q/E 명령으로만 전진 단수가 바뀝니다. Auto clutch가 꺼져 있으면 클러치 입력이 필요하고, 다운시프트가 최대 RPM을 넘길 경우 거절합니다. Auto clutch와 Rev match는 별도로 설정할 수 있습니다. 완전 수동에서 기어가 연결되고 클러치가 충분히 분리되지 않은 채 470RPM 미만이 0.45초 지속되면 스톨합니다. 재시동은 클러치를 80% 이상 밟거나 중립일 때 허용합니다. 자동 모드/자동 클러치는 저속 운전을 보조합니다. F2에서 스톨 기능을 끌 수 있습니다.

기본값: 아이들 850RPM, 최대 7,500RPM, 레드라인 7,200RPM, 기어비 3.30 / 2.20 / 1.58 / 1.20 / 0.97 / 0.80, 후진 3.10, 최종 감속 3.60, 변속 지연 0.22초. 출력은 토크 커브에서 계산하며 약 492hp입니다. Porsche 메시 기준 휠 반경은 앞 0.34047m / 뒤 0.35223m이며, 각 바퀴는 자기 반경을 사용합니다. Garage 기어 제한 이론치의 기준 반경은 후륜 평균입니다. 차종의 공식 제원 대신 게임용 기존 출력·질량 세팅을 유지합니다.

## 타이어 온도·마모

바퀴별 온도·마모를 유지하고 종·횡 슬립 일량 및 구름 일량으로 온도를 올립니다. 주행풍과 우천은 냉각을 강화합니다. 차가운 상태, 과열, 마모는 기본 노면 마찰 계수에 곱하는 그립 배율을 바꿉니다. 기본 주변 온도 20°C, 적정 온도 70°C, 열용량 계수 16,000, 냉각 계수 0.0012, 마모율 2e-8입니다. 타이어 공기압·카커스·트레드 다층 열전달까지 모델링한 것은 아닙니다.

시작 시 타이어는 70°C, 마모 0입니다. F3에 네 바퀴의 온도·마모·그립을 표시합니다. F2의 Service tires는 이 상태로 복구합니다. 세션 중 마모를 누적하지만 게임을 종료한 뒤 마모 이력을 영속 저장하지는 않습니다. F2에서 시뮬레이션을 비활성화할 수 있습니다.

## 입력과 시각화

스로틀, 브레이크, 조향은 각기 상승·복귀율을 적용합니다. 속도가 올라가면 최대 조향각이 줄어듭니다. HUD에는 실제 속도·RPM·기어·선택 상태, 입력량, 보조 개입, 등화 상태가 표시됩니다. F3에서는 FPS와 접지·슬립 등 디버그 정보를 봅니다. 바퀴 메시의 회전은 바퀴 각속도를 적분하고 앞바퀴에는 조향각을 적용합니다. 캘리퍼는 회전 휠과 분리되어 있으며 휠 높이는 서스펜션 길이를 따라갑니다.

Street는 기본 균형 세팅입니다. GT는 낮은 차고·높은 그립·다운포스, Drift는 낮은 후륜 그립과 TCS/ESC 해제, Wet는 AWD·완만한 출력과 높은 보조 강도, Eco는 출력 감소와 긴 최종 감속비를 적용합니다. 프리셋 이름은 성향을 나타내며 실제 차종 데이터가 아닙니다.

## 맵, 카메라, 오디오

도로 Curve3D는 메시 구성·미니맵·AI 교통·복구 위치에 사용합니다. 플레이어 차량 이동을 따라가게 하는 컨트롤러는 없습니다. 26,037.61m 도로에는 출발 직선, 계곡, 산길, 휴게소·소규모 건물, 교량, 지붕이 있는 갤러리, 상시 젖은 구간이 있습니다. 도로 표면·비 여부가 타이어 그립에 적용됩니다.

주변 5×5개의 256m 지형 타일을 관리합니다. 비용이 큰 지형 메시·식생 배치는 작업 스레드에서 만들고, 완성한 노드만 메인 스레드에 붙입니다. 종료할 때 새 생성을 멈추고 렌더 서버 요청을 처리할 시간을 준 뒤 스레드를 정리합니다. 로드 스레드를 메인 스레드에서 즉시 join하여 종료가 멈추던 문제를 수정했습니다.

카메라는 추적·범퍼·후드·운전석·회전형 외부의 다섯 모드입니다. 반경 0.16m 구체의 cast_motion 검사로 지형·벽·교통차 앞에서 위치를 제한하며, 감쇠 보간 후의 위치도 다시 검사합니다. 차종에 맞춘 모드별 오프셋 범위와 유한 FOV 제한을 적용하고 기존 카메라 설정은 v2로 초기화합니다. 운전석 기본 위치는 (-0.306, 0.22, 0.12)m입니다. 선스트립만 숨겨 도로 시야를 확보하고 다른 카메라에서 복원합니다. 외부 회전 거리는 3.4–15m로 제한합니다. 자신의 차체 충돌체는 검사에서 제외하므로 내부 시점은 메시 형태에 맞춘 제한으로 보호합니다.

엔진음은 850/1800/3000/4500/6000/7500RPM의 여섯 기준점마다 부하/코스트 2개, 총 12개 WAV를 피치 조절·교차 혼합합니다. TCS·변속 토크 컷이 적용된 실제 engine_load와 엔진 RPM을 사용합니다. 각 루프는 6기통 점화 주기를 표현한 주기 합성이며 녹음이 아닙니다. 시동·스톨·변속 이벤트, 슬립별 타이어음, 바람·노면·비·경적·충돌음을 더합니다. 운전석 2,600Hz/외부 12,000Hz 저역 통과 필터와 컴프레서를 사용하고 종료 시 전용 버스를 정리합니다.

새 엔진음은 `build_tools/generate_engine_audio.py`로 재생성합니다. 실제 녹음으로 교체하려면 assets/audio/의 `engine_<RPM>_on.wav`, `engine_<RPM>_off.wav` 파일명과 중심 RPM을 유지하고 루프 경계를 맞추거나 `car_audio.gd`의 anchors를 변경하십시오. 녹음 에셋은 이번 결과물에 포함하지 않았습니다.

노면에는 고주파 세부 normal, 식생에는 가지·알파 잎 카드와 MultiMesh·LOD를 적용합니다. 반사는 Low/Medium 하늘, High SSR 48 steps, Ultra SSR 96 steps입니다. ReflectionProbe를 사용하지 않아 Godot의 반사 아틀라스 7 Texture RID 종료 문제를 우회합니다. SSR 특성상 화면 밖 객체의 반사는 하늘 반사로 보완되며 완전한 오프스크린 동적 반사는 아닙니다.
