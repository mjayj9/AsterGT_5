## 확인된 문제와 수정

원본은 네 바퀴, 디스크, 서스펜션/캘리퍼, 스티어링이 이름과 계층으로 구분되어 있어 큰 모델링 작업 없이 주행용으로 변환할 수 있었습니다. 다만 바퀴 그룹의 원점이 모두 차량 원점이어서 그대로 회전시키면 바퀴가 차체 주위를 도는 문제가 생깁니다.

1. 장면 변환에 100배 스케일과 Godot 전방 축 정렬을 적용하고 앞뒤 축 사이를 중심으로 배치했습니다.
2. 타이어 경계에서 네 회전축을 계산했습니다. `Wheel_LF/RF/LR/RR` 아래에 타이어·휠·디스크를 묶고, `Caliper_*`를 분리했습니다. `Steering`도 실제 핸들 중심에 둡니다.
3. 이미 실체 림과 겹쳐 있던 STATIC/BLUR 대체 메시 8개를 활성 장면에서 제외했습니다. 143개 메시 노드를 사용하며 나머지 원본 버퍼도 파일에 보존됩니다.
4. 앞뒤 실제 반경을 각 바퀴의 접지·회전·슬립·제동 계산에 사용했습니다. 원본의 미세한 좌우 축 높이·위치 차이는 게임의 물리 마운트에서 좌우 대칭 평균으로 정렬했습니다. 이 보정 후 35초 평지 가속의 횡방향 편향은 0.0m였습니다.
5. 누락된 플라스틱·폼·알칸타라·전자장치 색과 과도하게 균일한 roughness/metallic 값을 보완했습니다. 원본 UV·텍스처·정점·인덱스·노멀은 유지했습니다. 게임은 차체 색, 유리 투명도, 등화·계기판을 별도로 제어합니다.
6. 실제 바퀴 각속도로 회전하고, 앞바퀴는 조향하며, 바퀴·캘리퍼 높이는 서스펜션을 따릅니다. 캘리퍼는 바퀴와 함께 회전하지 않습니다. 핸들도 조향에 반응합니다.
7. 운전석에서 시야를 막는 `INT_BANNER` / `EXT_Banner` 선스트립만 런타임에 숨기고 시점 전환 시 복구합니다. 차체 지붕·롤케이지를 삭제하지 않았습니다.

## 범위

이는 시각 모델 교체와 주행 연결입니다. 1,520kg·약 492hp 등 기본 동역학은 기존 ASTER의 게임 밸런스이며 실제 GT3 R 공학 모델은 아닙니다. 외형에 포함된 모든 스위치·와이퍼·미러를 기능화한 것은 아니며 기본 실내 디스플레이·핸들·등화를 연결했습니다. 사용자 파일에 적용된 비영리 라이선스 조건은 모델 수정 후에도 보존했습니다.
